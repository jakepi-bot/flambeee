# Design Decision Records

Rook (Game Designer) records contested calls, reversals, and tuning changes here so the next session does not relitigate them.

## Naming

`NNN-topic.md` — zero-padded sequence number, short slug. Example: `001-wordfire-streak-cap.md`.

## Rules

- Entries are append-only. Never rewrite a past decision; a reversal gets a new entry that names the old one and the reason.
- Each entry states the decision, the evidence behind it, and what would change the call.
- One decision per file. Keep it short: context, decision, reason, reversal condition.
