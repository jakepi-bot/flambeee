# Story 003 — 2048 Puzzle Game

**Priority:** P0 (this session)
**Epic:** v0.3.0 — Third game + difficulty selection
**Owner:** Ember (PM), Quinn (BA), Kai (Dev), Riven (Dev/Frontend), Scout (QA)
**Status:** Ready for development

## Business Need

Flambeee ships one game per session. Market scan (2026) confirms merge-puzzle classics like 2048 remain a top browser-game category — snackable, zero friction, no downloads. It rounds out the hub with a logic puzzle (Minesweeper = logic, Simon = memory, 2048 = strategy) and reinforces the "instantly playable" brand.

## User Story

As a visitor to the Flambeee Game Hub,
I want to play a classic 2048 merge-puzzle game,
So that I can relax with a quick, satisfying logic puzzle and chase a personal best score.

## Acceptance Criteria (BDD Scenarios)

### Scenario 1: Launch 2048 from the hub
- **Given** I am on the Flambeee Game Hub
- **When** I click the "2048" game card
- **Then** the 2048 game loads with a 4x4 grid and two starting tiles

### Scenario 2: Merge tiles with arrow keys / swipe
- **Given** I am playing 2048 with at least two equal-valued adjacent tiles
- **When** I press an arrow key (or swipe) in that direction
- **Then** the equal tiles merge into one tile with their summed value
- **And** a new random tile (2 or 4) spawns after each valid move

### Scenario 3: Score tracking
- **Given** I am playing 2048
- **When** two tiles merge
- **Then** my current score increases by the merged tile's value

### Scenario 4: Win condition
- **Given** I am playing 2048
- **When** I create a tile with value 2048
- **Then** a win message is shown
- **And** I may choose to continue playing or end the game

### Scenario 5: Game over detection
- **Given** the grid is full with no possible merges
- **When** no valid moves remain
- **Then** a game-over message is shown with my final score

### Scenario 6: Best score persistence
- **Given** I finish a 2048 game with a score higher than my previous best
- **When** the game ends (or I continue after winning)
- **Then** my best score is saved to localStorage and displayed on the next visit

### Scenario 7: Difficulty selection (from hub)
- **Given** I am on the Game Hub
- **When** I choose a difficulty (Easy 4x4, Standard 4x4, Hard 5x5)
- **Then** 2048 opens with the corresponding grid size
- **And** the difficulty label is shown in the game

### Scenario 8: Keyboard + mobile support
- **Given** I am playing 2048
- **When** I use arrow keys or WASD (desktop) or swipe gestures (mobile)
- **Then** tiles move in the corresponding direction

## Visual / Wireframe Description (Quinn)

- **Layout:** Centered 4x4 (or 5x5 on Hard) square grid. Score and Best tiles above the grid, Restart button beside them. Match Flambeee dark theme (consistent with Minesweeper/Simon).
- **Tiles:** Rounded squares; color intensity scales with value (2 = light, 2048 = brightest). Value shown as the number on the tile.
- **Feedback:** Merged tiles briefly pulse/scale to show the merge. Win and game-over overlays with restart action.
- **Controls:** Arrow keys + WASD on desktop; swipe on mobile (touch-optimized, no lag).

## Compliance / Standards

- No data collection, no PII. All state (best score) stored locally in the browser. No network calls. Accessible: tiles are legible text (not color-only); keyboard operable.
