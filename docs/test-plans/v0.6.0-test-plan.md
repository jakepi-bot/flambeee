# v0.6.0 Test Plan — Wordfire (Daily Word Game)

**Version under test:** v0.6.0 (feature/v0.6.0-wordfire)
**Author:** Scout (QA)
**Date:** 2026-08-11
**Stories covered:** 007 (Wordfire)

## Scope

- Daily puzzle: seeded by date, one per day, lockout after resolution
- Guess validation against word list
- Tile coloring with standard Wordle duplicate-letter rules
- Win/loss detection and overlay
- Daily streak (increment, persistence, gap reset) and best streak
- Practice mode (random puzzles, no streak impact)
- Stats integration (`flambeee-stats-wordfire`)
- Physical + on-screen keyboard, mobile layout
- Colorblind mode (shape symbols)
- Private-mode safety, brand consistency

## Edge cases

- Rapid Enter spam: only one commit per submit (gameOver guard + length check)
- Empty word list edge: `WORDFIRE_ANSWERS` / `WORDFIRE_GUESSES` must load before game init (script order)
- `dayIndex` boundary: UTC-based so all timezones get the same daily word
- localStorage JSON corruption: try/catch falls back to defaults
