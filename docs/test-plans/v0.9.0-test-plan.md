## Edge cases covered

- Private mode (localStorage throws): loadDist/saveDist wrapped in try/catch, defaults returned.
- Corrupt distribution JSON: validation rejects and falls back to zeroed shape.
- Daily already solved, page reloaded mid-session: `recordedThisDay` flag + persisted daily lock prevents double count.
- Practice wins/losses: never touch distribution.
- 2048 screenshot truthfulness: scripted state uses the game's own `data-v` values and classes.

None. All automated checks and browser smoke tests passed on first full run (one earlier script iteration produced a full-page 2048 capture; corrected the board selector and re-captured).
