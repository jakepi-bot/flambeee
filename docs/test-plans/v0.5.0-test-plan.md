# v0.5.0 Test Plan — Game Stats + Simon Difficulty

**Version under test:** v0.5.0 (feature/v0.5.0-stats-difficulty)
**Author:** Scout (QA)
**Date:** 2026-08-09
**Stories covered:** 005 (Game Stats Tracking), 006 (Simon Difficulty Levels)

## Scope

- Per-game stats tracking (Minesweeper, Simon, 2048) via localStorage
- Stats display on the Game Hub
- Simon difficulty levels (Easy / Classic / Hard) with per-difficulty best scores
- Regression: existing gameplay, best scores, board size persistence

## Test Cases

### Stats — Minesweeper

| # | Case | Steps | Expected |
|---|------|-------|----------|
| S1 | Play counted on loss | Start Easy game, click a mine | `flambeee-stats-minesweeper.plays` increments by 1 |
| S2 | Play + win counted | Win an Easy game | `plays` +1, `wins` +1 |
| S3 | Best time recorded | Win in 10s, then win in 8s | `bestTime` = 8 |
| S4 | Best time not regressed | Win in 8s, then win in 12s | `bestTime` stays 8 |
| S5 | Stats persist | Play, reload page | Counts unchanged |
| S6 | Private mode safe | Block localStorage, play a game | Game works, no console error |

### Regression

## Edge Cases

- localStorage unavailable (private mode): all games must still function; stats silently skipped
- Corrupt stats JSON: `loadStats` returns defaults, no crash
- Simon: switching difficulty mid-sequence must not leave pads disabled
- 2048: win overlay then continuing to game over must not double-count plays
