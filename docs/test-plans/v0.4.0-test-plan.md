## Edge Cases

- Rapid successive swipes: no double-move glitches (moves are synchronous).
- Swipe threshold: taps (< 20px movement) do not trigger moves.
- localStorage unavailable (private mode): game still runs; best score and size fall back to defaults silently.
- 5×5 board: all scenarios above apply; grid renders 5 columns.

## Known Limitations (documented, not blocking)

- Merge pulse marks the *result* tile position; the two source tiles visually collapse into it via the slide. Acceptable for v0.4.0.
- `touch-action: none` on the board-wrap means the board area itself never scrolls the page — intentional (game area is fixed-size). Page background uses `overscroll-behavior: none` to kill bounce.
