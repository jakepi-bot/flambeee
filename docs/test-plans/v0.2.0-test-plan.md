# Test Plan: v0.2.0 — Game Hub + Simon

**Author:** Scout (QA)
**Date:** 2026-07-31
**Scope:** Stories 001 (Game Hub) and 002 (Simon Memory Game)

---

## Test Cases

### TC-001: Hub page loads correctly
**Priority:** P0
**Steps:**
1. Open `src/index.html` in browser
2. Verify title shows "🔥 Flambeee Games"
3. Verify two game cards visible: Minesweeper (💣) and Simon (🧠)
4. Verify each card has name, description, and "Play" button
**Expected:** Hub renders with both games, dark theme applied

### TC-002: Hub → Minesweeper navigation
**Priority:** P0
**Steps:**
1. Click "Play" on Minesweeper card
2. Verify `src/minesweeper.html` loads
3. Verify Minesweeper game is functional (same as v0.1.0)
4. Click "Back to Games" link
5. Verify return to hub
**Expected:** Bidirectional navigation works

### TC-003: Hub → Simon navigation
**Priority:** P0
**Steps:**
1. Click "Play" on Simon card
2. Verify `src/simon.html` loads
3. Verify Simon game displays with 4 colored pads and Start button
4. Click "Back to Games" link
5. Verify return to hub
**Expected:** Bidirectional navigation works

### TC-004: Simon — Start game
**Priority:** P0
**Steps:**
1. Click Start button
2. Verify one pad flashes
3. Verify round counter shows "1"
**Expected:** Game starts, first pad in sequence flashes

### TC-005: Simon — Correct sequence
**Priority:** P0
**Steps:**
1. Start game, watch sequence flash
2. Click pads in correct order
3. Verify game accepts input
4. Verify sequence grows by one
5. Verify round counter increments
**Expected:** Correct input advances the round

### TC-006: Simon — Incorrect sequence
**Priority:** P0
**Steps:**
1. Start game, watch sequence
2. Click a wrong pad
3. Verify error indication (red flash or overlay)
4. Verify score displayed (rounds completed)
5. Verify Play Again button appears
**Expected:** Wrong input ends game with score display

### TC-007: Simon — Best score persistence
**Priority:** P1
**Steps:**
1. Play game, achieve score of 5
2. Refresh page
3. Verify best score shows 5
4. Play again, achieve score of 3
5. Verify best score still shows 5
**Expected:** localStorage persists best score across sessions

### TC-008: Simon — Audio feedback
**Priority:** P1
**Steps:**
1. Start game
2. Verify each pad flash produces a distinct tone
3. Click each pad manually
4. Verify each pad produces its tone on press
**Expected:** Audio feedback present and distinct per pad

### TC-009: Hub — Mobile layout
**Priority:** P1
**Steps:**
1. Open hub on mobile viewport (375px width)
2. Verify game cards stack vertically
3. Verify cards are tappable
**Expected:** Responsive layout works on mobile

### TC-010: Simon — Mobile layout
**Priority:** P1
**Steps:**
1. Open Simon on mobile viewport (375px width)
2. Verify pads are sized for touch (min 80px)
3. Verify Start button is tappable
4. Play a round on touch
**Expected:** Touch interaction works, layout fits mobile screen

### TC-011: Minesweeper regression
**Priority:** P0
**Steps:**
1. Open Minesweeper from hub
2. Play through Easy difficulty
3. Verify all v0.1.0 features still work: flagging, timer, reset, win/lose
**Expected:** No regression from v0.1.0

### TC-012: Cross-browser check
**Priority:** P2
**Steps:**
1. Test hub + both games in Chrome
2. Test hub + both games in Firefox
3. Verify consistent appearance and behavior
**Expected:** Works in major browsers

## Edge Cases

- **EC-001:** Rapidly clicking Start during a sequence → should ignore input during playback
- **EC-002:** Clicking Back to Games mid-game → should work, game state discarded
- **EC-003:** localStorage disabled → best score should show "—" or gracefully degrade
- **EC-004:** Very long sequence (20+) → game should continue without performance issues
